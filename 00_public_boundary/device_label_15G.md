# Device Label: 15G

## Purpose

This file defines the internal device label `15G` used in this repository.

The purpose is to prevent misunderstanding of the device name.

---

## Internal label

Repository label:

`15G`

This is an internal forensic / timeline label.

It is used to track a device lineage and Apple ID-related history across the reviewed artifacts.

---

## Physical device class

The reviewed artifacts indicate an iPhone 12 mini class device.

Observed model identifier:

`iPhone13,1`

Observed OS generation:

`iPhone OS 18.5 / 22F76`

---

## Important clarification

`15G` does not mean that the physical device is an iPhone 15 Pro.

The label `15G` is used because this device is associated with an Apple ID / Ghost lineage originally connected to an iPhone 15 Pro-related history.

Therefore:

* `15G` = internal Ghost / Apple ID lineage label
* `15G` ≠ physical iPhone 15 Pro
* observed physical class = iPhone 12 mini class device
* observed model identifier = `iPhone13,1`

---

## Why this matters

Some artifact names, notes, or internal references may include `15G`.

A reviewer should not interpret that label as the hardware model.

The correct interpretation is:

The repository uses `15G` as a continuity label for a device/account lineage under review.

The physical device class should be determined from the artifact metadata, not from the internal label.
